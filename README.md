# LinguaQuest

## Предметна область

Навчальний застосунок для коротких уроків англійської мови
та тренування перекладу базових слів.

## Користувач

Людина, яка починає вивчати англійську мову.

## Основний сценарій

Користувач вибирає переклад слова та отримує результат перевірки.
Кнопка «Підказка» показує підказку, якщо вона доступна.

Після першої помилки можна відповісти повторно. Правильна відповідь
дає 1 бал, дві помилки знімають 1 бал. Підказка не впливає на бали.

Наприкінці показуються кількість правильно виконаних запитань
і підсумкові бали. Кнопка «Пройти ще раз» починає урок заново.

## Основні сутності

| Сутність | Дані                                                |
|----------|-----------------------------------------------------|
| Question | Слово, варіанти відповіді, правильний індекс, підказка |
| Lesson   | Назва уроку та масив запитань                         |

## Реалізовані конструкції Swift

Спільні моделі та перевірка відповідей — у `Sources/LinguaQuestCLI`,
інтерфейс iOS — у `iOS/LinguaQuest/LinguaQuest/ContentView.swift`.

| Конструкція         | Приклад                                    |
|---------------------|--------------------------------------------|
| struct              | Question, Lesson, ContentView               |
| class               | AnswerChecker                              |
| protocol            | AnswerChecking                             |
| enum                | AnswerResult                               |
| let                 | Поля моделей, lesson, checker               |
| var                 | Бали, кількість відповідей, стан запитання  |
| Ініціалізатор       | Question.init(...), Lesson.init(...)        |
| Обчислювана властивість | Lesson.questionCount, currentQuestion   |
| Статичний метод     | Lesson.beginner()                           |
| Метод екземпляра    | AnswerChecker.check(answerIndex:question:)  |
| Масиви              | Question.options, Lesson.questions         |
| Optional            | Question.hint, currentQuestion             |
| Безпечне розгортання | if let, guard let                          |
| Умови та цикли      | if, guard, switch, for, while               |
| Стан SwiftUI        | @State у ContentView                       |

## Поточний стан

Реалізовано консольну та iOS-версії зі спільними моделями.
iOS-застосунок запущено в симуляторі. Перевірено проходження
з правильними й неправильними відповідями та підрахунок балів.
