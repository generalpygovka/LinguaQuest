# LinguaQuest

## Предметна область

Навчальний застосунок для коротких уроків англійської мови
та тренування перекладу базових слів.

## Користувач

Людина, яка починає вивчати англійську мову.

## Основний сценарій

Користувач проходить урок, вибирає переклади та отримує результат.
Підказка доступна через кнопку в iOS або команду `?` у консолі.

Правильно виконане запитання дає 1 бал.
Після першої помилки можна відповісти повторно.
Після другої помилки запитання завершується без нарахування балів
і показується правильний переклад. Підказка не витрачає спробу.

Наприкінці показуються кількість виконаних запитань і бали.
В iOS кнопка «Пройти ще раз» скидає результат.

## Основні сутності

| Сутність | Дані                                                   |
|----------|--------------------------------------------------------|
| Question | Слово, варіанти відповіді, правильний індекс, підказка |
| Lesson   | Назва уроку та масив запитань                          |

## Архітектура iOS

- ContentView відображає стан і передає дії користувача.
- LessonViewModel готує дані та повідомлення для екрана.
- LessonSession керує спробами, балами та проходженням.
- LinguaQuestApp створює компоненти й передає залежності.

Архітектура, Observer, SOLID та аналіз антипатернів:
[docs/architecture.md](docs/architecture.md).

## Підготовка та запуск

Xcode: 16.2. Мінімальна версія iOS: 18.2.

1. Клонувати весь репозиторій зі збереженням структури папок.
2. Відкрити `iOS/LinguaQuest/LinguaQuest.xcodeproj`.
3. За потреби встановити компонент iOS Simulator.
4. Вибрати схему LinguaQuest, симулятор iPhone та натиснути Run.

Додаткові бібліотеки та налаштування доступу не потрібні.

## Перевірка сценарію

- «Яблуко», «книга», «сонце»: 3 із 3, 3 бали.
- Для apple вибрати «вікно», потім «книга»; для book — «стіл»,
  потім «книга»; для sun — «сонце»: 2 із 3, 2 бали.
- Дві помилки на кожне запитання: 0 із 3, 0 балів.
- Для apple і book підказки доступні, для sun — відсутня.
- «Пройти ще раз» скидає бали, запитання та повідомлення.
- У консолі введення `abc`, `0`, `4` повторно запитує відповідь.

## Автоматичні перевірки

У LinguaQuestTests перевіряються проходження, бали, підказки,
повтор, некоректні дані та заміна перевіряльника тестовим.
Окремий тест перевіряє повідомлення підписника про зміну балів.

Запуск: вибрати тестову схему в Xcode та натиснути ⌘U.

## Поточний стан

Реалізовано консольну версію та iOS-сценарій через MVVM.
Моделі й перевірка відповідей розташовані в
`Sources/LinguaQuestCLI`, iOS-код — у `iOS/LinguaQuest/LinguaQuest`.

Observer використовується через Combine і SwiftUI.
Спільна бібліотека, репозиторій уроків, Builder і Decorator —
наступні етапи.
