# LinguaQuest

## Предметна область

Навчальний застосунок для коротких уроків англійської мови
та тренування перекладу базових слів.

## Користувач

Людина, яка починає вивчати англійську мову.

## Основний сценарій

Користувач вибирає переклад слова та отримує результат перевірки.
Кнопка «Підказка» показує підказку, якщо вона доступна.

Після першої помилки можна відповісти повторно. Правильна відповідь
дає 1 бал, дві помилки знімають 1 бал. Підказка не впливає на бали.

Наприкінці показуються кількість правильно виконаних запитань
і підсумкові бали. Кнопка «Пройти ще раз» починає урок заново.

## Основні сутності

| Сутність | Дані                                                |
|----------|-----------------------------------------------------|
| Question | Слово, варіанти відповіді, правильний індекс, підказка |
| Lesson   | Назва уроку та масив запитань                         |

## Поточний стан

Реалізовано консольну та iOS-версії зі спільною бібліотекою
`LinguaQuestCore`. Бібліотека підключається до CLI через `Package.swift`,
а до iOS — як локальна залежність Xcode з кореня репозиторію.
iOS-застосунок запущено в симуляторі. Перевірено проходження
з правильними й неправильними відповідями та підрахунок балів.

## Підготовка та запуск

Xcode: 16.2. Мінімальна версія iOS: 18.2.

1. Клонувати весь репозиторій зі збереженням структури папок.
2. Відкрити iOS/LinguaQuest/LinguaQuest.xcodeproj у Xcode.
3. За потреби встановити компонент iOS Simulator.
4. Вибрати схему LinguaQuest, симулятор iPhone та натиснути Run.

Додаткові бібліотеки та налаштування доступу не потрібні.

Консольна версія запускається з кореня репозиторію:

```text
swift run --build-system native LinguaQuestCLI
```

## Перевірка сценарію

- Вибрати «яблуко», «книга», «сонце»: результат 3 із 3, 3 бали.
- Для apple вибрати «вікно», потім «книга»; для book — «стіл»,
  потім «книга»; для sun — «сонце»: результат 2 із 3, 1 бал.
- Перевірити кнопку «Підказка»: для apple і book є текст,
  для sun — повідомлення про відсутність підказки.
- Натиснути «Пройти ще раз»: повертається перше запитання,
  бали та повідомлення скидаються.
