## Предметна область

LinguaQuest — навчальний застосунок для коротких уроків
англійської мови.

## Користувач

Користувач — людина, яка починає вивчати англійську мову
та хоче тренувати переклад базових слів.

## Основний сценарій

Користувач проходить урок: читає англійське слово, вибирає
один із запропонованих перекладів та отримує результат перевірки.
Після завершення уроку бачить кількість правильних відповідей.

Проходження всього уроку буде підключено на наступному етапі.

## Основні сутності

| Сутність | Дані                                                                             |
|----------|----------------------------------------------------------------------------------|
| Question | Слово, варіанти перекладу, індекс правильної відповіді та необов’язкова підказка |
| Lesson   | Назва уроку та масив запитань                                                    |

## Реалізовані конструкції Swift

| Конструкція                 |   Розташування |
|-----------------------------|--------------------------------------------|
| struct                      | Question.swift, Lesson.swift               |
| class                       | AnswerChecker.swift: AnswerChecker         |
| protocol                    | AnswerChecker.swift: AnswerChecking        |
| enum                        | AnswerChecker.swift: AnswerResult          |
| init                        | Question.swift, Lesson.swift               |
| Обчислювана властивість     | Lesson.questionCount                       |
| Статичний метод             | Lesson.beginner()                          |
| Метод екземпляра            | AnswerChecker.check(answerIndex:question:) |
| Масиви                      | Question.options, Lesson.questions         |
| Optional                    | Question.hint                              |

| Умови                       | AnswerChecker.swift: guard та if           |

## Поточний стан

Створено модель запитання, початковий урок і перевірку відповіді.
Консольна програма поки показує одне запитання.
Повне проходження уроку та iOS-проєкт буде додано на наступних етапах.
