# LinguaQuest

Навчальний застосунок для коротких уроків англійської мови.

Проєкт розробляється з нуля командою із двох студентів.

Поточний етап: створено Swift-пакет і першу консольну програму,
яка виводить назву та привітання. Розробка логіки виконується на Windows.

iOS-проєкт у Xcode поки що не створений.
