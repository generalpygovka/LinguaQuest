# LinguaQuest

## Предметна область

Навчальний застосунок для коротких уроків англійської мови.

## Користувач

Людина, яка починає вивчати англійську та тренує переклад слів.

## Основний сценарій

Користувач вибирає переклад слова та отримує результат перевірки.
Правильно виконане запитання дає 1 бал. Перша помилка дозволяє
відповісти повторно, друга завершує запитання з 0 балів
і показує правильний переклад.

Підказка доступна кнопкою в iOS або командою `?` у консолі.
Вона не витрачає спробу. Наприкінці показуються правильні
запитання та бали. В iOS доступне повторне проходження.

## Основні сутності

| Сутність | Дані                                                |
|----------|-----------------------------------------------------|
| Question | Слово, варіанти, правильний індекс, необов’язкова підказка |
| Lesson   | Назва уроку та масив запитань                        |

## Архітектура

iOS використовує MVVM. Обидві версії працюють зі спільною
бібліотекою `LinguaQuestCore`, зокрема з одним `LessonSession`.

| Частина          | Розташування                       |
|------------------|------------------------------------|
| Спільна логіка   | Sources/LinguaQuestCore             |
| Консольний ввід і вивід | Sources/LinguaQuestCLI/main.swift |
| Інтерфейс і ViewModel | iOS/LinguaQuest/LinguaQuest    |

Реалізовані патерни: Builder, Decorator та Observer.
Схема, SOLID, впровадження залежностей і технічні рішення:
[docs/architecture.md](docs/architecture.md).

## Підготовка та запуск

Xcode: 16.2. Мінімальна версія iOS: 18.2.

1. Клонувати весь репозиторій у папку LinguaQuest.
2. Відкрити `iOS/LinguaQuest/LinguaQuest.xcodeproj`.
3. За потреби встановити iOS Simulator.
4. Вибрати схему LinguaQuest, симулятор iPhone та натиснути Run.

Спільний пакет підключено локально. Зовнішніх залежностей немає.

Консоль із кореня репозиторію: `swift run LinguaQuestCLI`.
На налаштованому Windows-середовищі:
`swift run --build-system native LinguaQuestCLI`.

## Перевірка сценарію

- Правильні відповіді: 3 із 3, 3 бали.
- Дві помилки на apple, правильна відповідь на book із другої
  спроби та правильна на sun: 2 із 3, 2 бали.
- Підказка й некоректний консольний ввід не витрачають спробу.
- Для sun показується повідомлення про відсутність підказки.
- «Пройти ще раз» скидає результат і повідомлення.
